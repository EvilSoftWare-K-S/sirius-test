# Chip List Component

Адаптивный React компонент для отображения списка чипсов с автоматическим скрытием элементов в попап.

## Стек

- **React**
- **TypeScript**

## Возможности

- **Компактное отображение** - все элементы в одну строку, не поместившиеся скрываются в попап
- **Адаптивность** - автоматически подстраивается под изменение ширины экрана
- **Выбор элементов** - поддержка одиночного и множественного выбора
- **Модульность** - компонент Chip может использоваться отдельно
- **TypeScript** - полная типизация
- **FSD** - расширяемая архитектура
